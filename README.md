# MIDI Keypad

My custom MIDI keypad project, designed in KiCad using a Waveshare ESP32-S3-Zero.

## Features

- Seven capacitive touch keys
- Two sliding potentiometers
- One rotary encoder
- USB connection through the microcontroller

The keypad is intended to send MIDI notes and control messages once the firmware is implemented.

## Project files

- `MIDI-KEYPAD.kicad_sch` — circuit schematic
- `MIDI-KEYPAD.kicad_pcb` — PCB layout
- `MIDI-KEYPAD.kicad_pro` — KiCad project settings
- Gerber ZIP — exported PCB manufacturing files
- Screenshot — project preview

## Current progress

The schematic and PCB layout have been created. Firmware, physical assembly, and hardware testing are still pending. Manufacturing files still need final verification.
